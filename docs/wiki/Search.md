# Search

The magnifying glass at the top right of the window, or **Ctrl+K** (**Cmd+K**
on a Mac, or Ctrl+F), opens the search bar. Type what you are looking for, and
it searches as you type.

## What it finds

| Kind | Found by | Choosing it |
|---|---|---|
| **Setting** | Every control in [[Settings\|Workspace and Settings]]: its label, its tooltip and the names of its choices. "flats" finds Accidental preference | Opens Settings on its panel, with the control ringed for a moment |
| **Setting** (a panel) | The panel's name and description | Opens Settings on that panel |
| **Tool** | The tool's name, and other names it answers to ("notation" finds the Score View) | Opens the tool |
| **Command** | What the menus offer: open a score, the Library, the sample, theme, demo mode, mute, import and export settings, arranging the workspace, clearing the target, feedback; and with a score open, play, stop and record | Runs it |
| **Workspace** | Its name | Switches to it |
| **Song** | Its title, composer, parts and file name, from your [[Library]] | Opens it |
| **Take** | Its song, when it was recorded, what it used and how it ended | Reviews it in Take Review |
| **Lyric** | A line of the open score's lyrics, whole words, whatever bars it spans | Moves the playhead to where the line starts |
| **Bar** | "bar 12" | Moves the playhead to that bar |

Each result shows what kind it is on the left, and where it is underneath:
which Settings panel, which composer, which bar and part.

## How it matches

- **Every word you type must match**, so each word narrows the list: "click
  take" finds the setting about counting in, not the metronome.
- **The last word can be half-typed**: "metr" finds the metronome.
- **A word of four letters or more can be one letter out**: "refrence" finds
  Reference pitch.
- **Case and accents do not matter**: "gesellen" finds *Gesellen*.

## Moving around

| Key | Does |
|---|---|
| **↓** and **↑** | Choose a result |
| **Return** | Act on it (or click it) |
| **Escape** | Close the search bar (or click anywhere else) |

The search is always in your interface language, and always up to date: it is
rebuilt from what is open and what is in your library each time you open it.
